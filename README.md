# Personal Portfolio — Ruslan Kryzhanskiy

A personal portfolio website built with React and Vite, showcasing my front-end development projects and skills.

## Live Demo

[ruslan-oss-max0.github.io/portfolio](https://ruslan-oss-max0.github.io/Portfolio/)

## Built With

- React 18
- Vite
- CSS Modules / Custom CSS
- CSS Custom Properties
- Intersection Observer API

## Features

- Responsive design — mobile and desktop
- Smooth scroll navigation
- Project cards with live and GitHub links
- Image lightbox with keyboard support (Escape to close)
- Scroll-triggered fade-in animations
- Mobile burger menu
- Downloadable CV

## Project Structure

src/
├── components/ # React components
├── data/ # Projects data
├── hooks/ # Custom React hooks
├── styles/ # CSS files
└── assets/ # Images

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/Ruslan-oss-max0/portfolio.git
cd portfolio
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Deployment

```bash
npm run deploy
```

Deploys to GitHub Pages via the `gh-pages` branch.
